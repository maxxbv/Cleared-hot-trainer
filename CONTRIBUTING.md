# Contribuição

Usar Conventional Commits: feat, fix, docs, build, test e chore.

Executar testes públicos e scripts/audit.ps1 antes de propor mudanças. Integração também exige compilação/contratos locais e relato separado de validação em missão.

Nunca incluir DLLs, metadata, wrappers, dumps, assets, saves, credenciais, backups ou logs pessoais. Não usar Git LFS para contornar exclusões.

Não adicionar multiplayer, evasão de anticheat, alterações persistentes de binários originais, desativação de segurança do Windows ou exigência desnecessária de administrador. Descrever resultados observados e testes não executados.

## Licença das contribuições
