# Análise técnica versionável

Somente relatórios resumidos escritos para o projeto. Dumps completos de C#, código nativo, símbolos e wrappers derivados do jogo ficam em work, ignorados.

Não adicionar binários, assets ou trechos extensos de código proprietário. Identificadores/assinaturas mínimas fundamentam os pontos de integração. Ver metadata-and-patches.md e loader-compatibility.md.
